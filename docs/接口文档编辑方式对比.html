物料主数据同步接口

关联需求：VPMS × SAP B1 — 物料主数据双向同步

版本：v1.0    状态：设计中    负责人：张工

最后更新：2026-07-28 by 李四

1. 接口概述

VPMS 将新增物料数据后，通过该接口同步至 SAP B1；SAP B1 中物料的成本价变更后同步回 VPMS。

⚠️ 注意事项：物料编码在 VPMS 和 SAP B1 中必须使用统一编码规则。 首次全量同步由数据迁移脚本完成，接口仅处理增量同步。

2. 请求方式

POST   /api/v1/material/sync

Content-Type：application/json

认证方式：Bearer Token (OAuth 2.0)

3. 请求参数

参数名类型必填说明
materialCodestring是物料编码，最大 20 位
materialNamestring是物料名称
specstring否规格型号
unitstring是基本计量单位
syncDirectionenum是同步方向：VPMS_TO_SAP / SAP_TO_VPMS

4. 响应示例

{"code": 200, "message": "success", "data": {"syncId": "SYNC202607001"}}

方案 A：自由编辑（Wiki / 富文本）

  • 灵活度高，可自由组织内容和排版
  • 适合文档差异性大、格式不固定的场景
  • 学习成本低，像写 Word 一样编辑
  • 可插入图片、附件、代码块、表格等
  • 缺点是格式不统一，难以机器解析
  • 接口参数靠人工约定，容易遗漏字段
  • 多人协同时风格容易不一致
  • 无法自动校验或生成 API 规范文件

方案 B：结构化模板（表单填充）

  • 字段固定，多人编写保持格式一致
  • 必填校验，防止遗漏关键信息
  • 可自动生成标准接口文档和变更记录
  • 支持导出为 OpenAPI / Swagger 规范
  • 参数表格可联动类型、长度、必填校验
  • 不同角色可分别维护不同字段区域
  • 缺点是不适合非接口类需求文档
  • 模板调整需要开发介入，灵活度受限
