## 1. 项目定位

本项目是一个面向企业内部业务系统的**需求开发管理平台**，用于管理与跟踪多个业务系统的需求全生命周期。区别于通用 IT 项目管理工具，本系统特色在于：

- 多系统并行管理（外部采购 + 内部自研）
- 甲方-供应商-最终用户三方协作
- 跨系统需求关联与同步管理
- 严谨的三方权限隔离与分级管控

## 3. 用户角色与权限（已确认）

### 3.1 三类用户

| 用户类型 | 定义 | 组织架构 | 内部角色分级 |
|---------|------|---------|------------|
| 内部 IT 团队 | 企业信息化部门 | 独立维护 | 超级管理员 / 项目经理 / 项目成员 |
| 供应商团队 | 外部软件开发商 | 独立维护 | 项目经理 / 开发人员等 |
| 系统用户 | 各业务部门员工 | 独立维护 | 待细化 |

### 3.2 权限规则

| 用户类型 | 数据可见范围 | 备注 |
|---------|------------|------|
| 内部 IT — 超级管理员 | 全局所有数据 | 可查看和操作所有项目、需求、任务 |
| 内部 IT — 项目经理 | 按分配范围 | 非全员超管 |
| 内部 IT — 项目成员 | 按分配范围 | — |
| 供应商 | 仅可见被分配的项目、需求、任务 | 行级数据隔离 |
| 系统用户 | 仅可见自己提交的需求 | 行级数据隔离 |

### 3.3 供应商账号管理

- 供应商账号由内部 IT 管理员预先创建
- 一个供应商团队内区分项目经理、开发人员等角色
- 无需供应商自行注册

## 4. 核心业务流程（已确认）

### 4.1 需求状态流转

```
待审核 → 已分配 → 开发中 → 测试中 → 待上线 → 已上线 → 已验收
```

### 4.2 需求拆分

- 需求下可拆分子任务
- 甲方和供应商均可拆分任务
- 任务支持分配、状态跟踪、到期提醒

### 4.3 跨系统需求管理

- 一个需求可同时关联多个业务系统
- 如"VPMS × SAP B1 对接"需求，同时在两个系统视图下可见
- 各系统侧独立管理各自的进度和状态

### 4.4 需求变更管理

- 需求变更纳入 MVP 范围
- 需记录版本变更（谁在什么时间改了什么）

## 5. 功能模块范围（已确认）

### MVP 范围（P0 / 必须有）

#### 模块一：项目（系统）管理
- 以业务系统为管理单元
- 系统基本信息手动维护（由内部 IT 管理员创建和编辑）
- 已关联需求的项目禁止删除（数据完整性保护）
- 项目文档存储与在线维护

#### 模块二：需求与变更管理
- 需求录入、编辑、删除
- 需求状态流转（7 个状态）
- 需求关联多个业务系统
- 需求版本变更记录
- 需求下拆分子任务
- 甲方审核与用户验收

#### 模块三：任务与进度跟踪
- 任务分配与认领
- 任务状态更新
- 任务到期配置与提醒
- 进度可视化

#### 模块四：缺陷与质量管理
- 缺陷提交
- 缺陷分级与分类
- 修复与复测跟踪
- 验收确认

#### 模块五：文档管理
- 项目级文档存储（上传/下载）
- 在线接口文档维护
  - 结构化模板：接口元数据（路径、方式、参数、类型、必填等）
  - 富文本区域：请求/响应 JSON 示例
- 需求变更版本记录

#### 模块六：权限与组织架构
- 三类用户各自独立的组织架构树
- 行级数据隔离（供应商仅见分配内容，系统用户仅见自己需求）
- 内部 IT 团队三级权限（超管 / 项目经理 / 项目成员）
- 内容级权限控制（不同角色不同操作权限）

#### 模块七：通知
- 集成 Outlook 邮箱
- 任务/需求到期提醒
- 支持配置提前通知时间节点（如到期前 N 天）
- MVP 仅做到期通知

#### 模块八：操作日志
- 完整的系统操作日志
- 可前端展示
