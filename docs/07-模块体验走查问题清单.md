## 二、确认的真实 BUG（优先修复）

### D1 [高] ✅已修复(2026-09-23, f1e5d23) tester 无法复测缺陷：verify 权限要求"项目成员"而非"缺陷提交人"
- 现象：BUG-2（待复测，提交人 demo.supplier_tester）在 tester 视角操作列只有"编辑"，无"复测通过/失败"。
- 根因：`DefectPolicy::verify()` 要求 supplier_tester 角色 + `defect.retest` 权限 + **缺陷所属项目的成员身份**；BUG-2 挂在 QA 项目（id=5），tester 仅是项目 1 的成员。
- 为什么必须修：缺陷闭环"测试提交→开发修复→测试验证"的最后一步执行人没有权限，流程死在"待复测"。
- 建议：verify/reopen 放行条件改为"缺陷提交人 或 项目成员中的测试角色"；同步核对 defect.retest 权限配置。

### D1b [高] ✅已修复(2026-09-23, f1e5d23) tester 工作台"待复测缺陷"统计口径错误
- 现象：BUG-2 待复测存在，tester 工作台 `pending_defects=0`、优先处理为空。
- 建议：统计口径改为"状态=待复测 且（提交人=我 或 我可复测）"。

### R7 [中] ✅已修复(2026-09-23, f1e5d23) 直接访问 /requirements/create 白屏报 Laravel 原文
- 根因：前端路由 `requirements/:id` 无数值约束，`create` 被当作 id 请求 `/api/requirements/create` → 404。
- 建议：路由改为 `requirements/:id(\\d+)`；错误页中文化（"页面不存在或已被删除"）。

### P1 [中] ✅已修复(2026-09-23, f1e5d23) 项目列表"状态"列渲染异常（三个视角观察到三种表现：空/显示描述/过淡）
- 复验：API `status_label="活跃"` 返回正常 → 纯前端列绑定/样式问题，不同角色看到的表现不一致。
- 建议：前端排查该列的字段绑定与徽标样式（不同角色的列配置可能不同），状态用标准彩色徽标。

### T3 [高] ✅已修复(2026-09-23, f1e5d23) 供应商 PM 无法新建任务：需求下拉筛选了不存在的状态
- 现象：新建任务弹窗"所属需求（选择已审核需求）"下拉无数据；需求状态机中根本不存在"已审核"状态（实际为 待审核/已分配/已验收/待上线/已上线）。
- 建议：核对任务表单需求筛选的状态值；无数据时给出原因提示。

## 三、动线断裂类（高优先级体验问题）

### R2 [高] ✅已修复(2026-09-23, 2361471) 需求详情没有"拆分任务"入口
PM 最高频动线"审核→拆分→分配"被迫切模块、重填上下文。建议：详情页关联任务区加"新建任务"，自动带入需求与项目。

### W1 [高] ✅已修复(2026-09-23, 0370ef5) 工作台待办与"我可执行的动作"不符
待审核需求的审核人是超管却计入 it_pm 待办且置顶，点进去无任何操作。建议：待办统计口径=当前用户可执行。

### W2 [高] 工作台视角未按角色定制
- it_member 看到的是无权的缺陷/规划数字，而非"我的任务"；
- requester 看到缺陷和发布风险，而非"我的需求进展/待我验收"；
- supplier 角色看到"发布风险"卡片但无处可去（无版本菜单）。
建议：工作台按角色出不同统计卡与优先处理队列。

### R4 [中] 提出人没有"待我验收"入口，验收记录不可见
列表无"待我验收"过滤/角标，详情页无验收记录（谁验收、何时、意见）。验收是提出人唯一需要动手的环节，目前完全找不到。

### V1 [高] ✅已修复(2026-09-23, 2361471) 发布门禁阻断后没有解决引导
"缺发布说明"只写"影响记录 0 项，请处理后重新检查"，不给"去哪补"的入口。建议：阻断项带操作链接（直达编辑弹窗对应字段）；"影响记录 N 项"仅用于记录型门禁。

### P4 [中] ✅已锁定(2026-09-23) 现状已满足 it_pm 找不到"新建版本"入口
版本列表页无新建按钮（API allowed_actions 有 create_version）。建议在版本列表页显著位置放"新建版本"。

### D2 [高] 供应商 PM 无法 triage/指派缺陷
待确认缺陷只有甲方能确认，供应商 PM 既不能确认也不能指派给自己团队。建议：至少开放"指派负责人"给供应商 PM，或明确提示"待甲方确认"。

### T1 [高] ✅已修复(2026-09-23, 0370ef5+2361471) 任务没有详情页
看任务描述/关联需求只能进"编辑"弹窗，且弹窗看不到需求/项目/状态/历史。dev 看不到要做什么（dev/tester 连需求菜单都没有）。建议：增加任务详情页（只读视图 + 操作区）。

### D4 [中] ✅已修复(2026-09-23, 0370ef5+2361471) 缺陷没有详情页、不能传附件
看不到描述全文/修复说明/流转记录；登记缺陷不能传截图。建议：缺陷详情页 + 附件上传。

## 四、信息缺失与表单体验（中优先级）

### 需求管理
- **R3** [中] 列表缺"执行负责人/期望完成/更新时间"列 — 提出人想知道"卡在谁手里、什么时候有结果"
- **R5** [中] 待审核需求列表无快捷审核（通过/驳回），只能逐条进详情
- **R6** [中] 已上线/已验收需求仍可"编辑" — 终态应冻结，改动走变更流程
- **R8** [中] 新建需求表单四处问题：优先级默认"高"（14 条里 12 条高，优先级失效）；描述无模板引导、无附件入口；提交按钮叫"保存"，提交后去向不明；"关联项目"可多选但无说明
- **R9** [中] 需求类型显示"类型 #1"（详情页映射缺失/演示数据字典不全）

### 任务管理
- **T4** [中] 已完成任务仍显示"编辑/分配"按钮；待开始任务可"挂起" — 操作集与状态机不匹配
- **T5** [中] 任务表单选需求不自动带项目（缺陷表单却可以）— 行为不一致，允许选矛盾组合
- **T6** [中] 截止日期无临期/逾期可视化，不支持排序
- **T7** [中] 操作后列表重排"跑位"、成功反馈弱

### 缺陷管理
- **D5** [低] 登记缺陷的需求下拉无编号（同名无法区分）；列表缺时间列；工作台缺陷优先级用词（高/中）与缺陷列表（严重 P1/一般 P2）不一致

### 项目与版本
- **P3** [中] 添加项目成员不能指定项目角色，角色列全是"项目成员"
- **P2** [低] 项目"供应商"列显示根组织名"供应商"（演示数据命名 + 内部项目应为"-"）
- **V2** [中] 门禁规则名全英文；版本列表"门禁摘要"列信息量低（"进入详情检查"）；实际发布时间显示原始 ISO 串
- **V3** [低] 术语不统一：数据版本/并发版本（同为乐观锁）、待上线/待发布等阶段名映射不明

### 通用
- **W4** [中] 工作台"优先处理"缺待办原因/截止/负责人；统计卡跳转列表不带过滤条件
- **N1** [高] 站内通知未上线（铃铛禁用占位）— 属 Phase 4 范围；未上线前应隐藏入口而非展示禁用态
- **P8** [高] 没有用户管理模块 — 超管无法建号/禁用/分配角色（功能缺失，非 BUG）
- **O1** [中] 三棵组织树切换器不明显；组织操作全是裸图标（删除无说明）
- **O2** [低] 审计日志"目标"列不可跳转单据
- **F1** [中] 文档管理默认选中列表第一个项目，无权限时报错且"重试"无意义
- **G1** [低] 全局搜索只覆盖项目/需求，乙方日常对象（任务/缺陷）搜不到
- **W5** [低] 面包屑与标题重复；提出人无"提交需求"快捷入口；"待规划需求"术语难懂
- **R10** [低] 筛选必须手动点"查询"；修订历史英文且无 diff；"期望完成"常年为"-"；关联任务/缺陷不可点击
